PROJECT ARCTIC - WELCOME TO THE NEW ERA OF PC
Arctic - an innovative operating system, based off highly modified linux kernel with NT runtime parts built-in.
Looks and feels like Windows 11 in stock, but customizable in any way. Acts like windows 11 and runs most of it's apps, but in just more efficient way.
Idle RAM Usage below 2GB. UEFI x64 only, without useless legacy hardware support - Arctic were designed for modern PCs and laptops.
