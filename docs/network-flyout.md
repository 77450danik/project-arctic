# Мережевий флайаут: як у Windows 10

Джерело — розмітка самої Windows 10 (`NetworkUX.MainPage` у
`Windows.UI.ShellCommon.pri`, диск E:). Файли Windows 10 стиснені WOF
(CompactOS), ntfs3 віддає їх нулями: `ntfscat -a 0xC0` (алгоритм із точки
повторного розбору) + `ntfscat -n WofCompressedData` + розпаковка XPRESS/LZX
через wimlib (`D:\WORK_YT\tmp\xbf\wofcat.sh`, `wofdec.c`). XBF із PRI —
`pri_xbf.py`, у XAML — `out/tools-xbf2xaml` (завантажується в .NET через pwsh).

| Що | XBF | Що звідти |
|---|---|---|
| `NetworkUX.MainPage` | 0101 | розклад сторінки, `QuickActionControlStyle`, шаблони Wi-Fi |
| словник флайаута | 0081 | `EntityListItemControlTemplate`, тексти, `IconSize`, роздільник |
| кольори пунктів | 0086 | наведення, натиснення, вибраний |
| підключення / відключення | 0098, 0121 | `PreCFETemplate`, `ConnectedNetworkTemplate` |
| плитка | 0066 | `QuickActions.QuickActionControl` |
| акрил, посилання | 0082 | `SystemControlAcrylicElementBrush`, `HyperlinkAccentForegroundBrush` |

## Числа (DIP, ×DPI)

- Тло: акрил #101010 на 75% (= пресет «Windows 10» панелі задач; береться
  загальний вигляд оболонки). Ширина 360.
- Список: згори 12. Підключення (Ethernet, `ConnectionListTemplate`):
  значок MDL2 26 з полями 12,5,12,0; текст із полями 0,5,0,4, мін. 45.
- Роздільник: лінія 1 px `BaseLow` (#33FFFFFF), поля 12 з усіх боків.
- Wi-Fi (`EntityListViewItemStyle` + `EntityListItemControlTemplate`):
  відступи пункту 0,5,10,4; значок 24 завширшки (гліф 26) з полями 12,0;
  назва 15 біла; стан 15 `BaseMedium` (#99FFFFFF), під ним 6.
  Наведення — `SystemAltHighColor` 10%, натиснення 20%, вибраний — колір
  акценту.
- Вибраний: вміст із полями 48,4,0,0, панель 299 завширшки, знизу 4:
  «Підключатися автоматично» (прапорець) і «Підключитися» або лише
  «Відключити» — кнопка з полем згори 12, мін. 148, праворуч.
- Посилання «Налаштування мережі та Інтернету»: 15, колір
  `SystemAccentColorLight3`, поля 12,5,12,0; опис — Caption 12,
  непрозорість 0,6, поля 12,−5,12,12.
- Швидкі дії: 85×64, поля 4,0,0,4; ToggleButton Reveal з відступами
  3,7,0,3: гліф 16 угорі ліворуч, назва Caption 12 внизу, до 2 рядків.
  Вимкнена — `BaseLow`, увімкнена — акцент, натиснута — `BaseMediumLow`.
