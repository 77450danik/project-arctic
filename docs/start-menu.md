# Меню «Пуск»: план

Що треба: другий стиль у «Властивостях панелі задач → Меню "Пуск"» робочий і
за замовчуванням, а саме меню — двоколонкове, як на еталонній картинці
(Windows 7 у темному оформленні Windows 10/11): акриловий блюр, який компонує
dwm на GPU, заокруглені кути, значки й відступи точно як на картинці.

## Що є зараз

- ReactOS має лише класичне меню: `CStartMenu` (`dll/win32/shell32/shellmenu`)
  будує каскад папок «Програми», «Документи», «Настройка»… через `CMenuBand`.
- Перемикач «Меню "Пуск"» є (`base/shell/explorer/trayprop.cpp`), вибір пишеться
  в `SHELLSTATE.fStartPanelOn`, але explorer його не читає: меню завжди класичне.
  Кнопка «Налаштувати…» для нього нікуди не веде.
- Акрил, заокруглення, анімації появи вже вміє dwm (`dwmcore/gl.c`): акрил —
  розмиття того, що під вікном, на GPU (на залізі — Mesa/NVIDIA, у QEMU —
  llvmpipe). Вікно отримує його через `SetWindowCompositionAttribute`
  (`WCA_ACCENT_POLICY`), кути — `DWMWA_WINDOW_CORNER_PREFERENCE`, появу —
  `DWMWA_ARCTIC_TRANSITION`. Так уже зроблені Alt+Tab, мініатюри, флайаут
  гучності.

## Еталон (картинка), розміри при 100%

Вікно ≈ 420 × 530, кути 8 px, рамка 1 px #FFFFFF 15%, темний акрил
(тон ≈ #202020 на 80%).

**Аватар** — коло ≈ 64 px, сіре з білою фігурою людини, виступає над верхнім
краєм над правою колонкою (центр ≈ x 340). Клік — папка користувача.

**Ліва колонка** ≈ 255 px:
- програми, рядок ≈ 38 px: значок 32 px з відступом 8, текст 14 px (білий);
  у програм зі списками переходів — шеврон «>» праворуч (Блокнот, Paint,
  PowerShell на картинці);
- під списком — роздільник і «Усі програми» з «>», рядок ≈ 32 px;
- внизу — поле пошуку ≈ 240 × 26: біле, заокруглення 3, лупа ліворуч,
  підказка «Пошук програм і файлів» (сірим).

**Права колонка** ≈ 150 px, значки 20 px монохромні лінійні (стиль Segoe
Fluent), текст 14 px, рядок ≈ 38 px, групи з проміжками:
1. ім'я користувача, Документи, Зображення, Музика, Завантаження;
2. Недавні документи «>», Цей ПК;
3. Панель керування, Параметри, Оновлення;
4. Виконати…

**Внизу праворуч** — «Завершення роботи» зі значком живлення і «>»: клік
вимикає, стрілка — меню (Перезавантаження, Вийти, Заблокувати, Сон).

Наведення — #FFFFFF 10%, натискання — 20%, вибраний клавішами — рамка
фокусу; поява — виїзд знизу з затуханням, як у Windows.

## Як будувати

### Де живе

Нова Wine-бібліотека `startui.dll` у `runtime/wine/modules/dlls/startui`
(Win32 + GDI, як `sndvolsso`/`twinui`), яку explorer завантажує й викликає
`ArcticStartMenuShow(rcButton)`. Чому не всередині explorer (ReactOS):
Wine-модуль збирається й перевіряється локально за хвилини (WSL + QEMU), а
ReactOS — лише в CI. Explorer (патч ReactOS) лише вирішує, яке меню
показати: `fStartPanelOn` → `startui`, інакше — класичне `CStartMenu`. Клавіша
Win, клік по «Пуск» і Ctrl+Esc ідуть тим самим шляхом.

### Етапи

1. **Каркас і вигляд** (≈3–4 дні)
   - вікно з акрилом, кутами 8, тінню, появою; розкладка точно за еталоном;
   - вектор­ні монохромні значки правої колонки (папки, ПК, панель,
     шестерня, оновлення, «Виконати», живлення, шеврони) — малюються, як
     `sndvolsso/glyph.c`, або генеруються `tools/` у набір ICO;
   - аватар: малюнок облікового запису з реєстру, інакше намальована фігура;
   - клавіатура: стрілки, Enter, Esc, Win, набір тексту одразу в пошук.
2. **Права колонка** (≈1–2 дні)
   - відомі папки через `SHGetKnownFolderPath` (уже є в shell32, патч 0018);
   - «Недавні документи» — каскад папки Recent (`CMenuBand`, як у класичному);
   - «Цей ПК», «Панель керування» — відкриття або каскад, як налаштовано;
   - «Параметри» — поки Панель керування (власного застосунку немає);
     «Оновлення» — сторінка релізів Arctic, доки немає оновлювача;
   - «Виконати…» — `RunFileDlg`.
3. **Ліва колонка** (≈3–4 дні)
   - закріплені програми (перетягування й «Закріпити в меню "Пуск"» у
     контекстному меню ярлика) + часто вживані: облік запусків
     (`UserAssist` як у Windows — лічильник у HKCU, оновлюється при запуску з
     меню, панелі задач і `ShellExecute`);
   - «Усі програми» — каскад `CStartMenu`/`CMenuBand` по
     `Start Menu\Programs` (спільна й користувача), у стилі меню;
   - списки переходів: недавні файли програми з папки Recent за асоціаціями
     (`SHAddToRecentDocs`), пізніше — `ICustomDestinationList`.
4. **Пошук** (≈2–3 дні)
   - по ярликах меню, аплетах панелі керування, відомих папках, як Windows 7:
     результати замість лівої колонки, групами «Програми», «Панель
     керування», «Файли»; Enter відкриває першу;
   - індекс у пам'яті, оновлення за `SHChangeNotify` на папках меню.
5. **Завершення роботи** (≈1 день)
   - кнопка й меню поверх наявного шляху вимкнення (winlogon, як класичне
     меню вже робить); Сон — коли буде керування живленням (M6).
6. **Налаштування й типове** (≈1 день)
   - перемикач у властивостях панелі задач активний, «Налаштувати…» —
     діалог Windows 7: кількість недавніх програм, кожен пункт правої колонки
     «посиланням / меню / не показувати»;
   - `fStartPanelOn = 1` у `runtime/registry/arctic.reg` — двоколонкове меню
     за замовчуванням.
7. **Тести й доводка** (≈2 дні)
   - `tests/vm/m8-start-menu.txt`: відкриття клавішею й кліком, наведення,
     «Усі програми», пошук «блок» → Блокнот, «Завершення роботи ▸»;
   - звірка зі знімком еталона піксель у піксель: відступи, шрифти, кольори.

Разом ≈ 2–3 тижні.

## Ризики

- Шрифт: Segoe UI недоступний, буде системний шрифт теми; метрики тексту
  трохи інші — підганяти відступи під наш шрифт, не під Segoe.
- Значки Fluent — пропрієтарні: лише власні векторні копії.
- `CMenuBand` для «Усіх програм» малює класичні меню; темний стиль для нього
  — окремий патч ReactOS (або власний каскад у `startui`).
