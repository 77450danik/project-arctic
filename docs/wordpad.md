# Arctic WordPad

Текстовий процесор Arctic у вигляді Word для Windows 11: заголовок вікна з
пошуком посередині, стрічка (Основне, Вставлення, Макет, Вигляд), сторінки на
сірому полі, сторінка «Файл». Відкриває й зберігає DOCX, а також RTF, TXT;
ODT лише відкриває. Замінює WordPad з Wine: `runtime/wine/modules/programs/wordpad`
(файл `.replace`).

## Частини

| Файл | Що робить |
|---|---|
| `main.c` | вікно без системного заголовка, свій заголовок, команди, відкриття й збереження |
| `ribbon.c`, `popups.c` | стрічка, меню з двоколірними значками, кольори, таблиця, символи, шрифти |
| `view.c` | хост riched20 без вікна (ITextHost): сторінки, масштаб, миша, друк, рядок стану |
| `backstage.c` | сторінка «Файл»: останні документи, відомості, друк |
| `docx.c` | DOCX → RTF при відкритті, RTF riched20 → DOCX при збереженні |
| `zip.c` | ZIP (zlib Wine), читач XML |
| `image.c` | картинки через WIC, метафайли → PNG |
| `styles.c` | стилі галереї з іменами Word (`Heading1`, `Title`, …) |

Значки кнопок малює `tools/wordpad-icons.py` (на основі дизайнів
`tools/menu-icons.py`, тих самих, що в контекстному меню). Значки програми й
документів — We10X (`tools/wordpad-app-icons/make.py`, потрібен `rsvg-convert`,
є в arctic-ros).

## Сторінки

riched20 верстає текст однією колонкою завширшки з текст сторінки; колонку
ріжуть на сторінки між рядками й рядами таблиць. Межі дає повідомлення
`EM_ARCTIC_GETLAYOUT` (патч Wine `0133`); riched20 без нього (звичайна
Windows) — програма вгадує межі за `EM_POSFROMCHAR`. Миша в riched20 не
передається: 16 біт координат не сягають далі кількох десятків сторінок,
тож клік стає символом через `EM_CHARFROMPOS` (POINTL).

EM_FORMATRANGE у Wine немає: друк — другий екземпляр riched20 на контексті
принтера, ті самі межі сторінок.

## DOCX

- Читається: стилі з успадкуванням, шрифти теми, абзаци (вирівнювання,
  відступи, інтервали, табуляція, розриви сторінок), прогони, нумерація й
  маркери, таблиці (межі, заливка клітинки — як тло тексту), картинки
  (`w:drawing`, VML), гіперпосилання, поля (лише результат), елементи вмісту.
- Зберігається з пакета все, чого riched20 не показує: колонтитули, виноски,
  налаштування, власні стилі. Документ, картинки, нумерація пишуться заново.
- Адреси посилань riched20 не тримає: програма запам'ятовує їх за текстом
  посилання (синій підкреслений текст).
- Перевірка без вікна: `wordpad.exe /convert in.docx out.docx` (також `.rtf`,
  `.txt`), `wordpad.exe /rtf in.docx out.rtf`. З Git Bash — `MSYS_NO_PATHCONV=1`.
- `WORDPAD_LOG=<файл>` пише журнал малювання.

## Патч riched20 (`0133`)

- `EM_ARCTIC_GETLAYOUT`: блоки (рядки, ряди таблиць) з прапорцями розриву
  сторінки й «не відривати від наступного».
- Вирівнювання по ширині (`SetTextJustification` на пробіли рядка).
- Міжрядковий інтервал як у Word (множник, мінімум, точно); раніше
  1,5 і подвійний не діяли.
- Читання `\qj`, `\pagebb`, `\s`, `\slN\slmult1`; запис `\li`/`\fi` і
  інтервалу (були переплутані).

## Шрифти

Carlito і Caladea (OFL, `runtime/fonts`) мають метрики Calibri й Cambria;
`wordpad.reg` підставляє їх замість цих імен, Aptos → Arial.

## Картинки (патч `0134`)

Картинки документа riched20 тримає як OLE-об'єкт з метафайлом EMF
(`\emfblip`) і малює через `IViewObject::Draw` кешу даних ole32. Кеш Wine
малював лише METAFILEPICT і DIB, тож на місці кожної картинки лишалося
порожнє місце. Патч `0134` дає кешу EMF і точкові малюнки, а riched20, коли
кеш не може намалювати, малює картинку з її даних сам.

## Не зроблено

Колонтитули й виноски лише зберігаються, не показуються; .doc (Word 97–2003)
не відкривається; вирівнювання табуляції праворуч/по центру riched20 не
малює; межі клітинок riched20 малює лише на висоту першого рядка.
