# M2 — екран у Панелі керування: робочі нотатки

Як роздільність і частота оновлення доходять від `desk.cpl` до монітора, і що
для цього додано. Документ робочий: оновлюється, поки йде M2.

## Шлях зміни режиму

```
desk.cpl → ChangeDisplaySettingsEx(1280x800@75, CDS_UPDATEREGISTRY)
  → win32u: apply_display_settings → pChangeDisplaySettings
    → winewayland.drv: arctic_configuration_v1 (режим і позиція кожного монітора)
      → dwm.exe: kms_apply → DRM_IOCTL_MODE_SETCRTC
        → монітор перемикається, dwm розсилає нові події wl_output
      ← succeeded
    ← win32u: перечитує пристрої, WM_DISPLAYCHANGE усім вікнам
```

Зворотний напрямок (перелік пристроїв) — `pUpdateDisplayDevices`: список
моніторів з `wl_output`, позиції з `xdg_output`, EDID і відеоадаптер — з
`arctic_display_v1`.

## Що додано

| Частина | Де | Що робить |
|---|---|---|
| `kms.c` | dwmcore (unix) | усі підключені конектори картки, EDID, списки режимів, зміна режиму з відкатом, гаряче підключення через uevent |
| `compositor.c` | dwmcore (unix) | по `wl_output` на монітор, `xdg_output` з позиціями й назвами, `arctic_display_v1`, композиція у віртуальний екран і копія в буфер кожного монітора |
| `dwmcore.c` | dwmcore (PE) | політика: збережена розкладка для цього набору моніторів, інакше рідна роздільність і найвища частота; збереження в реєстр |
| патч `0029` | winewayland.drv | `arctic_display_v1` у клієнта: EDID, адаптер, `ChangeDisplaySettings` |
| патч `0030` | win32u | монітор з EDID — «Generic PnP Monitor», як у Windows |
| `desktop.c` | winsrv (csrss) | вікна з від'єднаного монітора повертаються на екран; про гаряче підключення дізнаються всі програми |
| патч ReactOS `0013` | desk.cpl | частота оновлення під роздільністю, усі режими монітора, назва моделі з EDID, справжні позиції моніторів |
| `dispmode.exe` | programs/dispmode | тестова програма: список пристроїв і режимів, зміна режиму з консолі |

## Правила, за якими вибирається режим

- **Перше завантаження:** рідна роздільність монітора (`DRM_MODE_TYPE_PREFERRED`)
  і **найвища частота**, яку монітор на ній тримає. Якщо `SETCRTC` не пройшов
  (кабель не тягне), береться наступна нижча частота, далі — режим, який монітор
  називає рідним.
- **Далі:** якщо для цього набору моніторів є збережена розкладка
  (`HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\Configuration\<набір>`),
  вона має перевагу — там лежить вибір користувача, як у Windows.
- **Зберігається** лише те, що програма застосувала з `CDS_UPDATEREGISTRY`
  (саме так робить Панель керування). Повноекранна гра міняє режим без цього
  прапорця, і після неї повертається збережений.
- **Другий монітор** стає праворуч від наявних зі своєю рідною роздільністю
  («розширити», як за замовчуванням у Windows); монітори, які вже щось
  показують, не чіпаються.
- Основний монітор завжди в точці 0,0 віртуального екрана: win32u рахує
  координати вікон саме від нього.

## Режими, які бачить Windows-сторона

- Тільки прогресивні: черезрядкові й `DBLSCAN` відкидаються.
- Один запис на розмір і цілу частоту: 59,94 Гц і 60,00 Гц — це один «60 Гц»
  (`DEVMODE` носить цілі герци). Точна частота лишається в dwm і йде в KMS.
- Частота рахується з таймінгів (`clock / (htotal * vtotal)`), а не з `vrefresh`.

## Перевірка без Панелі керування

`dispmode.exe` у dev-збірці (serial-shell):

```
setpriv --reuid=1000 --regid=1000 --init-groups env WINEPREFIX=/run/nt \
    HOME=/run/nt/home XDG_RUNTIME_DIR=/run/nt/xdg WAYLAND_DISPLAY=arctic-0 \
    wine dispmode.exe            # список пристроїв, моніторів і режимів
    wine dispmode.exe 1024x768@60   # перемкнути
    wine dispmode.exe restore       # повернути збережений режим
```

## Що ще лишилось у M2

- Кілька моніторів у QEMU не перевірити: у std VGA один вихід. Перевірка — на
  залізі (два виходи RX 580).
- Перетягування моніторів у desk.cpl (зміна розкладки) поки не працює: позиції
  показуються, але не застосовуються.
- «Додатково…» у desk.cpl показує лише загальну сторінку: `deskadp` і `deskmon`
  з ReactOS ще не збираються.
- Вимкнути окремий монітор («Приєднаний» у меню) поки не можна.
