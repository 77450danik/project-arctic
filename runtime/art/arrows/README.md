# Arctic's arrows

Back, forward and up of Explorer's toolbar and the address bar's Go button:
glossy blue-green arrows drawn for Arctic, cut from their drawing (one JPEG
on white) by `tools/extract-arrows.py` into 256-pixel PNGs with alpha.
`tools/make-toolbar-icons.py` scales them down to the toolbar's sizes;
`tools/compose-icons.py` uses them for the shell's other arrows.
